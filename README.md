# 坐姿闯关王 · Posture Quest

AI 姿态小游戏 — 浏览器本地运行，隐私安全，零成本。

🌐 在线体验：https://mingyi-blog.github.io/posture-guard/

## 是什么

坐姿闯关王用浏览器摄像头 + 本地 AI 模型，把「坐直」变成一局小游戏：坐得好连击涨、能量满、等级升；坐歪了连击断、能量掉。纯娱乐、纯本地。

- **纯本地推理**：视频与姿态数据全程在浏览器内处理，不上传任何画面或个人信息。
- **零网络依赖**：MediaPipe 模型已随仓库内联，打开即用，断网也能跑。
- **游戏化**：XP / 等级（10 级称号）/ 连击 / 里程碑成就，越玩越上头。
- **隐私可选**：支持画面模糊模式，只留骨架示意。

## 快速开始

1. 打开上面的在线链接（或本地双击 `启动.bat` / 运行 `python -m http.server` 后访问）。
2. 点「开始闯关」，坐好面对镜头，AI 会在 3 秒内自动记住你的标准坐姿。
3. 坐直攒连击、冲等级；坐歪连击断、能量掉，立刻调回来。

> 浏览器需通过 `https://` 或 `localhost` 访问才能调用摄像头。
