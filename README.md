# Posture Guard · 坐姿卫士

AI 实时坐姿监测工具 — 浏览器本地运行，隐私安全，零成本运营。

🌐 在线体验：https://mingyi-blog.github.io/posture-guard/

## 是什么

坐姿卫士用浏览器摄像头 + 本地 AI 模型，实时识别你的坐姿，给出评分与提醒，帮你在久坐时保持好习惯。

- **纯本地推理**：视频与姿态数据全程在浏览器内处理，**不上传任何画面或个人信息**。
- **零网络依赖**：MediaPipe 模型已随仓库内联，打开即用，断网也能跑。
- **游戏化激励**：XP / 等级 / 连击系统，让坚持监测更有动力。
- **隐私可选**：支持画面模糊模式，只保留骨架示意。

## 快速开始

1. 打开上面的在线链接（或本地双击 `启动.bat` / 运行 `python -m http.server` 后访问）。
2. 点击「开启摄像头」，坐好面对镜头，保持自然坐姿。
3. 点击「校准当前坐姿」——AI 会记住你的标准姿态作为基准。
4. 开始监测，屏幕实时显示评分，不良姿势会触发提醒。

> 浏览器要求通过 `https://` 或 `localhost` 访问才能调用摄像头。

## 合规与许可

- 姿态识别基于 Google MediaPipe（Apache 2.0）。
- 本工具仅作日常习惯提醒，**不构成医疗诊断或治疗建议**。
- 无任何外部 CDN 依赖、无密钥/Token、无隐私数据收集。
